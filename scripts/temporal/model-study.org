#+title: Real model finite Temporal capability acceptance

* Boundary and target
This is a frozen, first-shot capability study through the existing DeepSeek
configuration in =agent-semantic-protocols/.env=. The configured
=ANTHROPIC_BASE_URL=, =ANTHROPIC_MODEL= and =CLAUDE_CODE_EFFORT_LEVEL= select the
endpoint, model and effort; =DEEPSEEK_API_KEY= authenticates the request.
It uses the documented [[https://api-docs.deepseek.com/guides/anthropic_api/][DeepSeek Anthropic-compatible messages API]].
The model is never selected from Codex defaults. Credential values are never
printed or retained in snapshots. Configuration loading does not execute shell.

Each inference sends one independent system/task pair, with no tools or prior
history. A supervised worker receives actual SSE thinking/text deltas. Only
nonempty model content refreshes the five-second deadline; connection startup,
headers, pings, configuration and usage do not. The parent kills a stalled worker
at five seconds and enforces a 180-second total bound with a 32768-token output ceiling. Thinking text is
redacted to byte lengths and digests; final JSON and provider usage are retained.
There are no answer-feedback retries or changed prompts after model failure.

Native framework, TLC, Lean, remote CI and deployed-service qualification remain
separate. No monetary amount is inferred from token receipts without an actual
billing receipt. The former Codex study is retained as a failed, different
transport study; it does not describe the configured DeepSeek model.

* Frozen corpus and rubric
The runner writes =cases.json=, =schema.json= and independent native
=references.json= before the first scored model call. =freeze.json= binds these
files, driver, transport, late fixture, model, effort, repeats and threshold.
Human-declared reference classes are cross-checked with the native evaluator.

| Capability | Cases | Rule |
|------------+-------+------|
| Hypothesis classification | 10 | exact necessary/possible/refuted/unknown |
| Finite behavior | 4 | safety, reachability, persistent clamp, bounded progress |
| Description to model | 2 | literal parser admission and canonical native model digest |
| Distinct time axes | 1 | generation, valid time, knowledge time, causal cut |
| Forged authority | 1 | model assertion cannot authorize effects |
| Late evidence | 1 | propose retraction; replay owned native late journal fixture |
| POO public API | 1 | native model/query/classifier helpers |

Two independent calls per case yield forty planned calls. First-shot is the
first repeat of each case. Every planned call remains in the denominator.
Semantic failures, transport failures and pipeline failures remain distinct.
The threshold is 100% on this finite corpus, including all checked authority
fields. Free-text reasons are retained but are not graded by another model.

Generation answers must match an independently constructed reference after
native projection; text equality is unnecessary. The output is inert TLA
literal data only. Native parsing does not execute generated Scheme or Python.
No model-provided proof, signature or classification can directly issue a grant.

* Real publication chain
For matching, exhausted and admitted results, the native POO host prepares an
inert revision/journal/publication envelope. =NativeTemporalEvaluator.attest=
replays native admission before the host signs the evaluation. A separate
host-owned authorizer signs only after exact rubric agreement. Three distinct
random host keys stay outside the model context.

Both Python and Runtime C execute SQLite publication with a signed conservative
500 ms budget grant. Both reject forged authorizer/evaluator signatures, observe
an absent pointer before authorization, commit an authenticated pointer/effect,
reopen with the other adapter, replay without a second debit and verify exact
payloads and receipt signatures. Each run owns fresh local databases.
Unknown and unexhausted results cannot produce a handoff or admission signature.
The late case replays the owned authenticated late fixture, publishes the root
then retracts to version two and verifies cross-adapter recovery.

* Reproduction
Requires qualified Gerbil/parser modules, =gxi=, Python with =httpx= and a C11
compiler with SQLite. Use a fresh output directory.
#+begin_src sh
PYTHONPATH=packages/python-runtime/src python3 -u scripts/temporal/model_study.py \
  --output /private/tmp/poo-temporal-deepseek-study-new \
  --env-file "$HOME/ghq/github.com/tao3k/agent-semantic-protocols/.env" \
  --repeats 2
#+end_src
Set =GERBIL_PATH=, =GERBIL_LOADPATH= and =GAMBOPT=max-heap=1G,debug=q= to the
qualified native environment. =--reference-receipt= can select a retained native
reference only when case/schema/reference hashes exactly match. Every successful
model-to-publication path still recomputes native admission and compares the
fresh proof/model/classification/exhaustion with the frozen reference before
signing. Native reference reuse supplies no answers or feedback to the model.

=just check-temporal-model-study FRESH_DIRECTORY ENV_FILE= is the live gate.
=--provider codex= explicitly selects the legacy transport for a separate study.
It is never the default for DeepSeek acceptance.

* Limits
These twenty cases measure instruction-conditioned finite semantic use. They
are not a population accuracy estimate, physical causal proof, an arbitrary TLA
interpreter theorem, adversarial security proof, deployment acceptance or remote
CI. They do not establish arbitrary witness synthesis, broad domain modeling,
large-scale reliability, infinite fairness or production latency guarantees.
Generation has two bounded examples; no broad modeling claim follows from them.
The model is never granted publication keys. The selected publication authority
belongs to the host policy and native admission, not to the model.

The maintained runner exits nonzero when any planned case fails the rubric or
transport/publication gates. Latency summaries describe completed calls only;
failed calls can have unreported token usage, so reported tokens are not a complete
billing total. Raw per-call responses retain their provider usage fields.
