* Ownership and open bridge

The finite contract uses caller-owned symbol IDs and exact nonnegative
positions in a declared clock. A complete local answer does not authenticate
that clock, cut, source coverage or a claimed domain causal mechanism. A
hypothetical fork requires separately named source/cut inputs and retains its
hypothetical scope. Existing POO causal-event, causal-cut, revision and evidence
contracts continue to own source authority and domain-neutral assessment.

No automatic mapping from a POO causal-cut object's wire identity into this
finite lens is implemented. That mapping needs an explicit source-owner
clock/cut/admission contract with MRR. Interval uncertainty, generic temporal
fragment composition, Provider-update failure handling, broader scale and
release/deployment authority remain separate gates. The existing approved
four-call repair study stays bound to its earlier ASCENT =cd6f60f= and POO
=0b7a6c52=; this dependency update neither changes its frozen preview nor
spends any model-call budget. No model calls were made for this slice.

* Explicit bounded-time exchange v1

=modules/temporal-causality/ascent-exchange.ss= is an opt-in POO-native transport.
=poo-flow-ascent-event-binding= requires one text event identity, a distinct
non-reserved native symbol, a valid-time observed instant/bounded observation
(or =#f= for unknown), and a separately supplied observed knowledge instant.
=poo-flow-ascent-exchange= requires the owner graph/cut, one bijective binding
per graph event, source/generation/native-clock names, both domain identities,
and a finite window, knowledge cutoff, horizon and coverage declaration.

The bridge recomputes the cut from the graph and its logical cutoff. It rejects
cut relabeling, omitted/duplicate event bindings, unresolved parent mappings,
unobserved instants and domain mismatches. It never converts logical cut time,
acquisition time or a provenance label into a knowledge coordinate. The native
clock name identifies the caller-declared pair of axes; no clock conversion is
performed. Cut completeness is combined with the explicit coverage declaration.

The projected source name hashes the complete original graph/cut and canonical
bindings, including observation/provenance/receipt names. Thus equal native
rows cannot reuse a receipt after original metadata changes. This is content
consistency, not source authentication. Because that name identifies a single
exchange snapshot, the native =temporal-compare= API must not be used to compare
two such snapshot names across generations; a stable owner admission binding
is a separate gate. Solve/verify operate on the immutable projected values.

ASCENT now accepts closed uncertainty bounds for one valid-time point. These
are not event duration intervals. Membership in a half-open window is
=true= only when all possible positions lie inside, =false= only when all lie
outside, and =unknown= otherwise. Overlapping parent bounds retain an unknown
order frontier, even when both events are definitely inside the window. Known
reversed bounds reject the cut. Unknown bounds, late knowledge and open coverage
cannot produce complete native evidence or definitive absence.

* MRR admission boundary still required

The MRR facade at =fde89c72918f72e6cb8c925f5e11760ba019f328= admits canonical
facts/lineage and evaluated query/closure candidates. =RelationContext::validate=
checks source authority/provenance coherence; it does not admit external clocks,
POO event identities or cut coverage. This transport does not fabricate an MRR
admission receipt from a digest or a Boolean.

A future admission adapter must bind a canonical admitted semantic generation,
source fact identities, the full bijective event mapping, both declared axes,
cut coverage, and the exchange schema. It must reject stale generation/fact
bindings and partial/invalidated source contexts before promoting a native
candidate into MRR facts/lineage. External authentication and runtime effects
remain with their owners. Until that adapter is implemented, this exchange is a
locally verified finite snapshot candidate, not an admitted semantic transition.
