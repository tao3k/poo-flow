* Owned public roles

Session remains an independent Module. =objects-attempt.ss= contributes native
=SessionInputRef.=, =SessionTask.=, =SessionAttempt.= and =SessionSchedule.=
proposals to =objects.ss=. =types.ss= now defines their bounded input/task/schedule
Types and routing/capacity invariants. =funs-attempt.ss= closes through =funs.ss=
and =interface.ss=. No separate =session-core= Module is introduced.

The pure named functions =schedule=, =claim=, =complete=, =recover=, =reconcile=
and =close= use the =poo-flow-session-= prefix. Every transition returns an intent
with =runtime-published?=, =action-authorized?= and =durable?= false. The supplied
state is a proposal, never proof that an owner published it. A Host must load its
own current state, resolve producer/terminal/isolation receipts and atomically
publish with the expected revision and current use fences.

* Exact identities and bounded recovery

Session ID is bounded text. Each Attempt binds Task/specification revision,
Session ID, fresh Attempt ID, claim generation, Turn, provider request, exact
input reference and Org anchor references. Input references preserve producer,
contract, identity/digest, scope/source/Query/restriction/profile digests,
producer receipt reference and exact consumer Session/Turn. Claim rejects
foreign consumer bindings. Completion compares every routing and input field.
Attempt and input strings are copied before returning the claim proposal.

One active Attempt is supported per schedule in this first protocol. Recovery
increments owner revision and generation, moves the active Attempt into a pending
obligation and fences late completion. Recovery preserves pending obligations;
claim and close remain blocked until exact reconciliation is proposed. Runtime
reconciliation additionally requires an actual matching terminal or isolation
receipt; the pure intent does not supply one. Completed/reconciled Attempt IDs
cannot be reused. Coordinates are capped at 65535, with typed refusal before
wraparound, and terminal IDs are bounded at 128 without implicit eviction.
Closed Sessions cannot recover. This is bounded safety, not scheduler fairness,
provider preemption, persisted recovery or external-effect resolution.

* Context composition and Org references

Context's =funs-session.ss= produces an independent =SessionInputRef.= after
replaying the supplied original source bytes and exact Scope. A Session-bound
Scope is required. Context owns source/Query interpretation; Session preserves
references. =receipt-ref= identifies a producer receipt to resolve at publication;
caller creation or native shape admission does not authenticate that receipt.

Task =anchor-refs= are opaque admitted-reference proposals, copied into the
Attempt for exact routing. They are not extracted Org =:ID:= values and do not
yet prove an association between a Session and a parser-owned property ID.
Parser-backed Org property ID admission remains a required implementation gate.

* Executable qualification

The canonical normal-compiler PackageSpec build includes the new source roles.
Eight native Session cases cover textual identity/anchor preservation, eager
input copy, wrong request/Task/Turn/generation/Session/input/anchor rejection,
foreign consumer claims, once-per-Attempt completion, recovery obligations,
reconciliation/retry and closed/exhausted refusal. Thirteen Context Delta cases
cover existing patch controls plus real-byte incremental/full equality, bounded
local reuse, forged caches and source-replayed Context-to-Session input.
Native tests use =just test-file= and require =MODULE-OK=, =HARNESS-OK= and final
=OK=. Local qualification compiles only test artifacts with the previously
recorded O0 setting; production modules use the unchanged default compiler.

=SessionAttempt.lean= proves eight named routing/recovery laws; its axiom audit
inventories 13 theorems including generated declarations with standard Lean
axioms only. CI builds the separate =PooFlowAttemptProof= target. The finite
model and matched controls are documented in [[file:context-delta-lean-quint-model-design.org][the Context Delta model receipt]].
Source hash/invariant binding proves metadata freshness only. The native controls
are matched by condition; automated model trace-to-native replay is still absent.

* Remaining production gate

The actual current-source lineage, grant/policy generation, Session owner CAS,
producer receipt resolver, provider dispatch/disclosure, result admission and
terminal/isolation receipt resolver must share an explicit trusted coordinator.
The existing Context Use v1 six-field wire contract does not carry this complete
Attempt envelope. Define and qualify its successor with MRR and MRR Data
consumer pin changes. No consumer or ABI qualification is inferred from these
pure tests. Artifact-port readiness, concurrent scheduling, cancellation commands,
durable recovery and performance measurements remain separate work.
