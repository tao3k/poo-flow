* Normative responsibility

This module exclusively owns G0 semantic values, canonicalization, decision
reasons, and qualification cases.

* Semantic values

#+begin_src text
DependencyQualificationRequirement
ModuleImportObservation
QualificationPolicy
DependencyQualificationDecisionReceipt
#+end_src

All four are POO values.  Requirement contains:

#+begin_src text
requirementId
identity
imports
capabilities
#+end_src

The current requirement identity is =clan/poo=.  The required Gerbil module is
=:clan/poo/proto=.  Required procedure-shaped bindings are:

#+begin_src text
compose-proto*
instantiate-proto
instantiate-protos
#+end_src

All three binding shape predicates are named
=poo-flow.shape/procedure=.  The required capabilities are:

#+begin_src text
poo.prototype-composition
poo.prototype-instantiation
#+end_src

Requirement collections are POO objects with deterministic projections.  They
are not raw alists, package declarations, build inputs, or =gerbil.pkg=
dependency projections.

Observation contains only standard Gerbil module/import facts:

#+begin_src text
probeProtocolId
requirementDigest
moduleResults
#+end_src

It contains no package projection, build identity, provider selection, or GSLPH
attestation.

Each module result contains:

#+begin_src text
moduleIdentity
lookupResult              ; resolved | not-found
importChain
bindingResults
#+end_src

Each binding result contains:

#+begin_src text
bindingIdentity
lookupResult              ; present | missing
shapePredicateIdentity
shapeResult               ; true | false | absent
#+end_src

=shapeResult= is absent when the module or binding could not be obtained.  It is
never guessed from source text, a package declaration, or a build target.

POO Flow constructs Observation inside the runtime qualification transaction.
A runtime caller supplies Requirement and Policy only.  Caller-constructed
Observation or Decision values are invalid at the runtime entrypoint.

* Pure decision

The bounded semantic rejection reasons are:

1. =module-not-found=
2. =required-binding-missing=
3. =required-binding-shape-mismatch=

Unexpected probe failure is not a semantic rejection and produces no
DecisionReceipt.

Rejection precedence is deterministic:

#+begin_src text
module-not-found
  before required-binding-missing
  before required-binding-shape-mismatch
#+end_src

The pure Decision function follows:

#+begin_src text
if any required module is not-found
  reject module-not-found
else if any required binding is missing
  reject required-binding-missing
else if any present binding fails its named shape predicate
  reject required-binding-shape-mismatch
else
  pass
#+end_src

The DecisionReceipt contains only the decision protocol identity, Requirement,
Observation, and Policy digests, =pass=/=reject=, and the bounded reason code or
explicit absence.  It does not include a condition, event, source pin, build
receipt, runtime context, or harness result.

#+begin_mermaid
flowchart LR
    R["Requirement"] --> D["Pure Decision"]
    O["Observation"] --> D
    P["Policy"] --> D
    D -->|"pass/reject"| Receipt["DecisionReceipt"]
    ProbeFailure["Unexpected probe failure"] --> Condition["Structured condition"]
    ProbeFailure -. "no receipt" .-> Receipt
#+end_mermaid

* Canonical contract

- Canonical values use deterministic length-framed S-expressions.
- Collections use deterministic ordering.
- Text is NFC-normalized.
- absent, false, and empty remain distinct.
- Digests use tagged SHA-256.
- Runtime context, event, condition, build, package-manager, and GSLPH identities
  never enter canonical semantic material.

The canonical grammar is a deterministic length-framed S-expression grammar.
Map and set-like projections sort by canonical key bytes.  Duplicate semantic
keys are invalid rather than resolved by last-writer behavior.

The approved expected golden roots and byte lengths remain expectations until a
runtime transaction materializes them:

* Required cases

#+begin_src text
G0_REQUIRED_PURE_DECISION_CASES=4
G0_REQUIRED_LIVE_IMPORT_CASES=4
G0_REQUIRED_PRECEDENCE_BOUNDARY_CASES=2
G0_REQUIRED_PRECEDENCE_SENTINEL_CASES=1
G0_REQUIRED_EXECUTION_INSTANCES=11
#+end_src

The eleven instances have distinct responsibilities:

| Family | Instances | Responsibility |
|-
| pure Decision | P0–P3 | pass and each of the three semantic rejections |
| live/dev import witnesses | L0–L3 | matching live module, missing module, missing binding, shape mismatch |
| precedence boundaries | 2 | prove earlier rejection reason dominates a simultaneous later defect |
| precedence sentinel | 1 | prove no rejection is manufactured when all required facts pass |

Pure cases test the Decision function with constructed semantic values.  Live
witnesses test POO Flow's internal Observation construction against controlled
Gerbil module environments.  A live witness result is not itself a
DecisionReceipt.

GSLPH may execute these instances as a development harness.  It does not
construct runtime Observation, select a reason, issue a receipt, or attest that
an expected golden value is current.

* Source and operational evidence boundary

Dependency source pinning belongs exclusively to
[[file:45-06-gerbil-poo-api-alignment.org][45-06]].  A source pin proves which
implementation is intended; it is not a field of Requirement, Observation,
Policy, or DecisionReceipt.

The superseded archive's former =G0.1= source identity and =G0.2= runtime
consumption discussions remain historical evidence only.  They do not create
additional G0 root objects or receipt families.

The following are explicitly absent from this contract:

- active evidence closure;
- package/provider projection;
- direct/transitive/undeclared provider classification;
- =gerbil.pkg= declaration digest;
- Gerbil-Bazel source or build digest;
- GSLPH execution identity, stdout digest, or attestation;
- ambient checkout identity;
- child package integration/distribution result.
