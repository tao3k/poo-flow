* Logic gaps found by Lean

The owner-coverage closure proves that every non-committed step has exactly one
owner-native transition witness.  It did not yet preserve the exact receipt
identity of that witness across adjacent trace positions.

Lean exposed four distinct gaps.

** Budget accounting did not imply receipt freshness

The crash and storage advance contracts previously advanced the consumed and
remaining counters without requiring a new receipt identity.  The following
implication is invalid:

#+begin_src typst
$
  c_(i + 1) = c_i + 1
  quad and quad
  r_(i + 1) < r_i
  quad arrow quad
  "receipt-id"_(i + 1) != "receipt-id"_i
$
#+end_src

The independent theorem
=accountingAdvanceDoesNotDetermineReceiptFreshness= records this failure.

The actual crash and storage advance contracts now require
=receiptIdentityAdvances=, matching the existing scheduler contract.  This is a
strengthening of the canonical architecture, not a compatibility rule.

** Prop-valued owner coverage did not expose receipt data

=SourceBoundEffectCompletionRecoveryOwnerCoveredStep= proves that a native
transition exists.  Because it is proposition-valued, it is intentionally not
an audit data object and does not expose the selected receipt value to a later
trace position.

The audit layer therefore needs a first-class witness value whose fields are
bound back to the exact native transition receipt.

** Adjacent freshness did not imply global non-reuse

Suppose three locally valid transitions use one owner:

#+begin_src typst
$
  rho_0 : r_0 -> r_1,
  quad
  rho_1 : r_1 -> r_2,
  quad
  rho_2 : r_2 -> r_1
$
#+end_src

Every step is fresh and both adjacent boundaries are continuous, yet the third
step reuses the first step's resulting receipt identity.

The independent theorem
=localFreshnessAndAdjacencyDoNotPreventGlobalReceiptReuse= proves this
counterexample.  Global non-reuse is therefore an independent invariant.

** Owner receipt domains could not express cross-owner continuity

A runtime-crash receipt ID and a storage receipt ID belong to different native
domains.  Requiring equality between them would erase their ownership meaning.
Cross-owner continuity must instead use a common audit predecessor chain while
preserving each native receipt identity unchanged.

* Decision

Define one canonical
=SourceBoundEffectCompletionRecoveryOwnerAuditWitness= value for every
non-committed recovery position.

The witness contains:

- =witnessId=;
- =previousWitnessId=;
- =ordinal=;
- =recoveryId=;
- the exact =owner=;
- the exact =ownerIdentity=;
- =beforeReceiptId= and =afterReceiptId=;
- =runtimeEpoch=;
- =activeFenceToken=.

No field is interpreted through an older schema.  A missing, empty,
discontinuous, or reused identity is rejected.

* Canonical witness validity

For witness \(w_i\), validity requires non-empty witness, recovery, and owner
identities; a fresh owner receipt; and a predecessor shape consistent with the
ordinal.

#+begin_src typst
$
  "Valid"(w_i)
  := w_i."wid" != epsilon
  and w_i."rid" != epsilon
  and w_i."oid" != epsilon
  and w_i."before" != w_i."after"
$
#+end_src

#+begin_src typst
$
  i = 0 arrow w_i."previous" = "none"
  comma
  i > 0 arrow exists p, w_i."previous" = "some"(p)
$
#+end_src

Receipt freshness is required twice:

- by the native crash, scheduler, or storage transition contract;
- by the first-class audit witness validity predicate.

The theorem =ownerAuditBindingForcesReceiptFreshness= proves that a binding
cannot manufacture audit freshness independently of its native receipt.

* Native owner binding

=SourceBoundEffectCompletionRecoveryOwnerAuditBinding= has exactly three
constructors.

** Runtime crash binding

The constructor consumes:

- =SourceBoundEffectCompletionRecoveryCrashDeferralTransitionClosed=;
- =SourceBoundEffectCompletionRecoveryCrashDeferralProgressProjection=;
- equalities binding owner, recovery ID, runtime owner identity, before and
  after receipt IDs, runtime epoch, and active fence token.

It binds only =runtimeCrashBudget=.

** Scheduler binding

The constructor consumes:

- =SourceBoundEffectCompletionRecoverySchedulingDeferralTransitionClosed=;
- =SourceBoundEffectCompletionRecoverySchedulingDeferralProgressProjection=;
- equalities binding owner, recovery ID, scheduler owner identity, before and
  after receipt IDs, runtime epoch, and active fence token.

It binds only =schedulerAdmission=.

** Completion storage binding

The constructor consumes:

- =SourceBoundEffectCompletionPrecommitStorageDeferralTransitionClosed=;
- =SourceBoundEffectCompletionRecoveryStorageDeferralProgressProjection=;
- equalities binding owner, recovery ID, storage owner identity, before and
  after receipt IDs, runtime epoch, and active fence token.

It binds only =completionStorageAdmission=.

The theorem =ownerAuditBindingBuildsOwnerCoveredStep= projects every binding
back into the already-proved atomic owner coverage algebra.

* Adjacent audit continuity

Two adjacent non-committed witnesses satisfy:

#+begin_src typst
$
  "ordinal"_(i + 1) = "ordinal"_i + 1
  quad and quad
  "previous"_(i + 1) = "some"("witness-id"_i)
$
#+end_src

#+begin_src typst
$
  "recovery"_(i + 1) = "recovery"_i
  quad and quad
  "epoch"_(i + 1) = "epoch"_i
  quad and quad
  "fence"_(i + 1) = "fence"_i
$
#+end_src

When the owner is unchanged, the owner-native receipt chain must also be
continuous:

#+begin_src typst
$
  "owner"_(i + 1) = "owner"_i
  arrow
  "before-receipt"_(i + 1) = "after-receipt"_i
$
#+end_src

When the owner changes, native receipt IDs are not equated.  The shared
=previousWitnessId= edge is the cross-owner continuity proof.

* Global owner receipt non-reuse

The closure rejects reuse of the same native owner receipt at any later
non-committed position:

#+begin_src typst
$
  forall i, j,
  quad i < j quad arrow quad
  ("owner"_i, "after-receipt"_i)
  !=
  ("owner"_j, "after-receipt"_j)
$
#+end_src

The key contains the owner because native receipt identities belong to
owner-specific domains.  The theorem =reusedOwnerReceiptRejectsOwnerAudit=
enforces this invariant directly.

* Closure and convergence

=SourceBoundEffectCompletionRecoveryOwnerAuditEvidence= requires, for every
non-committed position:

- current source generation;
- stable provider acknowledgement;
- a valid canonical audit witness;
- a binding to one exact owner-native transition;
- adjacent audit continuity where the next position is also non-committed;
- global non-reuse of =(owner, afterReceiptId)=.

The proof projection is:

#+begin_src typst
$
  "owner-audit"
  arrow
  "owner-coverage"
  arrow
  "progress-evidence"
  arrow
  "recovery-convergence"
$
#+end_src

=closedOwnerAuditBuildsOwnerCoverage= performs the first projection.
=closedOwnerAuditConverges= reuses the existing convergence theorem without
changing the recovery progress or convergence semantics.

* AXLE-driven proof modularity

The first actual-closure AXLE preflight selected five roots from the heavy
native binding module.  That closure expanded to:

- 25 owner source files;
- 398 declarations;
- 86,389 source bytes.

AXLE reached its default 30-second =owner-source-extract= limit.  Increasing the
timeout would have hidden a module-boundary problem.

The canonical identity, adjacency, and non-reuse algebra was therefore moved
into
=SourceBoundEffectCompletionRecoveryOwnerAuditCore=.  Native binding now
depends on that core in one direction.

The qualified core closure contains:

- 2 owner source files;
- 21 preflight declarations;
- 3,166 source bytes;
- 8 exact declarations for 3 selected roots.

It completes under the unchanged default AXLE timeout.  No versioned
replacement API or compatibility alias was introduced.

* Fail-closed boundaries

The actual closure proves:

- =emptyWitnessIdentityRejectsOwnerAudit=;
- =brokenPredecessorRejectsOwnerAudit=;
- =reusedOwnerReceiptRejectsOwnerAudit=;
- =supersededNonCommittedStepRejectsOwnerAudit=;
- =unstableProviderRejectsOwnerAudit=.

There is no theorem that repairs, upgrades, defaults, or falls back from an
invalid witness.

* Next proof gap

The canonical witness chain preserves identity and rejects reuse, but
=witnessId= is still an uninterpreted non-empty string.  The next proof must
determine whether witness identity is content-addressed by the complete native
binding and predecessor commitment, and whether enterprise authenticity and
authorization evidence bind that commitment without moving policy semantics
into the recovery engine.
