#+title: Evidence receipts

The POO Flow source tree no longer tracks =*.log=. New Session/WorkTree
qualification uses registered Python cases and structured JSON receipts;
console output remains diagnostic progress, not a separate evidence artifact.
The structured =.json= and =.ss= receipts here retain their original log names
and SHA-256 values as historical assertions. A hash without its raw bytes is
not a locally replayable log qualification and does not establish current
source, authority or runtime behavior. Do not silently turn a historical
receipt into a current pass.

The removed log bytes remain recoverable from the pre-cleanup PR #34 commit
=79f1ec6f205afaf53580a916d858e051264ec38f= in Git history. Future
qualification should record producer revision, source cut, actual exit,
watchdog limits, semantic assertions, and result identity in typed receipts.
Raw process output is retained only when a bounded diagnostic artifact is
needed to investigate a failure. It is never an authority grant or a
substitute for a passing result.
