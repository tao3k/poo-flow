* Decision

Define four independent propositions over one
=AgentActionEvidenceEnvelope=:

1. =capabilityConfinement=: every granted capability is in the action's
   authorized capability set;
2. =toolIdentityClosed=: the resolved provider, implementation digest, and
   resolution digest equal the declared tool identity;
3. =effectContainment=: every observed effect is in the declared effect set;
4. =causalContinuity=: action, operation, observation, decision, previous
   root, and current evidence root form one continuous chain.

The complete closure is:

#+begin_src typst
$ "EnterpriseInvariantClosed"(E)
  = "EnvelopeClosed"(E)
  and "CapabilityConfinement"(E)
  and "ToolIdentity"(E)
  and "EffectContainment"(E)
  and "CausalContinuity"(E) $
#+end_src

* Capability confinement

Requested capability is not authority. The proof uses the authorized set:

#+begin_src typst
$ forall c in O."grantedCapabilities":
  c in A."authorizedCapabilities" $
#+end_src

Any granted capability absent from that set rejects the entire invariant
closure.

* Tool identity

Tool names are insufficient. Identity equality covers provider identity,
implementation digest, and resolution digest through
=AgentToolIdentity=. An adapter label or benign tool name cannot compensate
for a digest mismatch.

* Effect containment

For every observed effect:

#+begin_src typst
$ forall e in O."observedEffects": e in A."declaredEffects" $
#+end_src

The proof does not infer effect safety from successful execution, detector
confidence, or tool identity.

* Causal continuity

The causal invariant reuses envelope equalities rather than constructing a
parallel trace:

- observation action and operation match the intent;
- observation previous root matches the intent previous root;
- observation current root matches the envelope root;
- recovery action and observation dependencies match;
- recovery prior root matches the authoritative observation root.

* Counterexample theorems

Lean rejects:

- one unauthorized granted capability;
- one substituted tool identity;
- one undeclared observed effect;
- any broken causal-continuity proposition;
- a tool mismatch even when a source adapter is present.

* Architecture boundary

- These invariants define the provable region; they do not classify arbitrary
  natural-language intent.
- Detector output may select an obligation but cannot inhabit its proof.
- Unknown evidence escalates or fails closed in the decision layer.
- No runtime log format, JSON shape, or model-specific reasoning field enters
  the theorem surface.
