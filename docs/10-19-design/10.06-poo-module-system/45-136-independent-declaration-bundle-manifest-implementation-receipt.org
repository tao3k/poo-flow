* Implemented identities

The pure Python module defines:

- =AxleEnvironmentIdentity=: environment name, Lean toolchain, import surface,
  and optional pinned project source;
- =ResolvedSourceIdentity=: Lake-resolved package, revision, source-tree digest,
  and Lake manifest digest;
- =DeclarationIdentity=: declaration name, kind, owner path, owner source digest,
  and local dependency identities;
- =IndependentDeclarationBundle=: selected roots, toolchain, environment,
  sources, topologically ordered declarations, and canonical Lean source;
- =BundleValidationError=: stable fail-closed error code plus detail.

The schema identity is
=poo-flow.independent-declaration-bundle.v1=.

* Enforced invariants

The constructor rejects:

- unsupported schema identities;
- empty root, toolchain, environment import, source, declaration, or source text;
- different local and AXLE Lean toolchains;
- missing or duplicate root declarations;
- ambiguous resolved package sources;
- invalid SHA-256 identities;
- absolute or parent-traversing owner paths;
- duplicate declarations or local dependencies;
- self dependencies;
- roots outside the declaration closure;
- missing local dependencies;
- declaration orders that are not dependency-topological;
- project-aware environments without a pinned revision.

It does not parse Lean imports or declarations with regular expressions.  The
=local_dependencies= field must come from the future Lean-owned exporter.

  "SchemaSupported"(B)

  and "DeclarationsUnique"(B)
  and "LocalDependenciesComplete"(B)
  and "TopologicallyOrdered"(B) $

$ "SourceDigest"(B) =
  "SHA256"("CanonicalSourceBytes"(B)) $

$ "BundleDigest"(B) =
  "SHA256"(
    "CanonicalManifestJSON"(B)
    + "Separator"
    + "CanonicalSourceBytes"(B),
  ) $

$ not "ManifestValid"(B) => "BundleConstructionRejected"(B) $
#+end_src

Resolved sources and selected root sets are canonically sorted in the manifest.
Declaration order is preserved because it is itself the dependency-topological
proof input.
