The loop is a Building Framework extension around its existing effect
boundary.  It does not call =gsc= directly, create a per-spec =gxi= scheduler,
or overlap multiple =std/make= coordinators.  The toolchain gate does not pin a
machine-specific Xcode path and does not delete SDK selectors on every OS.  On
Darwin it preserves an existing non-Nix directory or resolves the active paths
through =xcode-select= and =xcrun=.  Linux preserves the host environment.
Every other host system is rejected instead of inheriting Linux behavior by
accident.
