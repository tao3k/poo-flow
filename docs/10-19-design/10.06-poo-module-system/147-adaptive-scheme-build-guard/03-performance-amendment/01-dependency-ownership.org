* 2026-07-27 dependency ownership correction

The former independent
=//scheme:dependency_source_contract_compile= action compiled a second
package/source declaration catalog inside POO Flow. It duplicated
=gerbil.pkg= and the Gerbil-Bazel build lock and was removed.

The current POO Flow Bazel graph calls Gerbil-Bazel
=gerbil_project_compile= directly. Gerbil-Bazel owns project-receipt
construction and validation, including =dependencySourceResolutions=. POO
Flow has no local generic receipt validator or wrapper rule.
