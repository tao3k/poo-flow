The pre-geometric compile log contains sixteen guarded runtime windows and two
guarded UI windows.  Their completed process-tree receipts remain below the
hard cap, but the runtime windows account for approximately 97.6% of the inner
build duration.  The old =window + worker-count= rule therefore makes the
number of coordinator sessions linear in =spec-count / worker-count= even
after the host has demonstrated safe spare capacity.  This receipt authorizes
capacity-capped geometric growth; it does not authorize removing the guard or
running concurrent coordinators.
