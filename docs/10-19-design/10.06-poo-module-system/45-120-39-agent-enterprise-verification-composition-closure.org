* Decision

=AgentEnterpriseVerificationClosed= composes five independently owned gates:

1. the current action inhabits the unified envelope and all four enterprise
   invariants;
2. the registered red-team scenario has a closed proof regression and the
   refined policy rejects it;
3. the three enterprise proof metrics derive from source-bound samples;
4. the current action and decision have a proved sample with the same evidence
   root;
5. the bundle verification and resolution receipts close against the
   envelope's =BundleSubject=.

The metrics and regression receipts must carry the same independent bundle
digest as the envelope.

* Composition law

#+begin_src typst
$ "EnterpriseVerified"(E)
  = "FourInvariants"(E)

#+end_src

No gate substitutes for another. In particular:

- detector precision does not prove an action;
- one proved action does not close aggregate metrics;
- a red-team regression does not establish source ownership;
- a green bundle receipt does not establish capability or effect
  confinement;
- successful replay does not authorize a new action.

* Theorems

Lean proves that a closed enterprise verification:

- carries capability confinement, tool identity, effect containment, and
  causal continuity;
- rejects the registered counterexample under the refined policy;
- reports the exact three derived metrics;
- carries a bound verification receipt for the envelope bundle;
- is rejected when the metrics bundle digest differs from the envelope.

* Architecture boundary

- This is proof composition, not a new runtime service.
- Runtime POO owners remain =ObservationEvent=, =RecoveryDecision=, policy,
  scheduler, effect, and bundle owners.
- Vendor adapters only project source records.
- AXLE remains optional independent qualification and is not a runtime
  dependency.
- No compatibility alias, second CLI, raw log DSL, or model-specific schema is
  introduced.
