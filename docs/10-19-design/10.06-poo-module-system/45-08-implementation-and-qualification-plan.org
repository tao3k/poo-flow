** Fail-closed evidence contract

The validator MUST reject missing source or test paths, stale source/test
symbols, duplicate or reordered row identities, duplicate generated targets,
and every owner path that crosses into a descendant checkout.  Bazel analysis
validates each generated target's source label.  The validator never executes
the child build, tests, publication, release, or distribution lifecycle.

The =gerbil-poo= row consumes the existing =//scheme:gerbil_poo_package= target
and =@gerbil_poo_sources//:source_resolution_receipt=.  It does not introduce a
package manager or another POO library.

The formal countermodels and closure theorems are owned by
=PooFlowProof.Enterprise.ModuleSystemOwnerMapClosure=.  They prove that an
=implemented= flag alone admits stale selectors and descendant lifecycle edges,
that schema/version alone admits missing rows, and that authority-bound closed
rows replay the same source, test, and build binding.

** Qualification evidence

The manifest is source configuration, not a stored pass result.  The validator
parses it as literal data and checks the current checkout on every execution.
It MUST NOT accept a checked-in receipt, source-content digest, timestamp, or
previous CI result as evidence that the current revision passed.  Bazel and CI
may emit ephemeral execution receipts for diagnostics and handoff, but current
acceptance comes only from executing the stable qualification target against
the current revision.

* Required test groups

In this RFC, “required integration groups” means only parent-owned
=poo-flow-core= cross-layer qualification.  It never includes a
=wendao-episteme= suite, another descendant-only suite, descendant
distribution qualification, or recursively executing a child package test
graph.  A descendant may qualify its consumption of an explicitly identified
parent artifact under its own owner and completion gate.

Benchmark and performance qualification remains owned by
[[file:80-observability-performance-gates.org][80]].  Such evidence may be
scheduled after the semantic tranches are green, but it is not a first-round
45-08 semantic gate and cannot redefine the contracts owned by 45-01 through
45-07.
