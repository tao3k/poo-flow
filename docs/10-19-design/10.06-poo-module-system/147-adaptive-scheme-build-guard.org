* Current ownership

The downstream guard implementation described by the earlier sections of this
RFC has been removed.  POO Flow does not own build-process sampling, heap/RSS
classification, compiler-job observation, worker admission, or abnormal-build
termination.  Its root =build.ss= declares the package with the public ASP
Gerbil Scheme =PackageSpec= API and composes the public native-build memory
guard around =clan/building#init-build-environment!=.  The upstream guard owns
its versioned
=asp-gerbil-scheme.build-trace.v1= and
=asp-gerbil-scheme.memory-anomaly-guard.v1= receipts.

The module tree below is retained as design and acceptance history.  The
normative downstream boundary is the Build API cutover in module 17 and the
upstream-only trace/guard convergence in module 20.  Historical local names,
environment variables, thresholds, and receipts must not be reintroduced as
POO Flow APIs.

* Module map

RFC 0147 is organized by responsibility.  This file is only the stable entry
point; policy, architecture, evidence, and historical receipts have independent
owners below.
