#+title: Fixed-Point Convergence and Observation Budget
#+startup: overview

* Status

Normative RFC.

* Scope

This RFC owns productive recursion, non-productive cycle detection, bounded
divergence, slow convergence, semantic progress, and observation-budget
authority around the sole =gerbil-poo= evaluator.

* Cycle identity and progress

A cross-submodule dependency cycle is legal until demand evaluation proves it
non-productive.  A cycle candidate is identified by:

#+begin_src text
(root identity,
 demand generation,
 module identity,
 Capability identity)
#+end_src

Repeated names do not establish a cycle.  Re-entry of the same demand cell is
legal while evaluation produces observable semantic progress.  Re-entry with
no progress produces a continuable non-productive-cycle condition.

The trace labels import, export, re-export, and submodule-boundary edges.
Cross-boundary recovery authority belongs to the smallest common demand
boundary that owns every edge.  External projection respects Capability
visibility while internal diagnostics retain the complete trace.

These rules instrument =gerbil-poo=; POO Flow does not implement another fixed
point or cycle evaluator.

* Semantic observation unit

A semantic observation unit is an immutable POO evidence object describing one
observed state transition.  It is not an iteration counter.

The unit carries root identity, demand generation, module or submodule instance
identity, Capability identity, predecessor and successor semantic-state
identities, prototype-lineage or contribution edge, source provenance, and
condition or evaluation phase.

Progress exists only when canonical predecessor and successor semantic
identities differ.  Repeating an equivalent transition consumes no progress
unit and enters no-progress or cycle observation.  One canonical transition
observed through multiple alias or re-export paths remains one unit.

Wall-clock duration, stack depth, allocation count, log volume, and effect retry
count are not semantic units.  Runtime pointers, closures, and continuations do
not enter unit identity.

The budget Capability consumes admitted semantic transition units.  POO Flow
projects transitions actually exposed by =gerbil-poo= and MUST NOT synthesize
progress.  If pinned API evidence cannot expose a required transition, the
alignment records an API gap rather than substituting a timer or guess.

    R["repeated equivalent transition"]

#+end_src

* Semantic convergence and host safety

Cycle detection, semantic divergence budgeting, and host resource safety are
independent controls:

- the cycle detector immediately conditions re-entry of the same demand cell,
  generation, and semantic state without waiting for budget exhaustion;
- the semantic progress budget handles evaluation that keeps producing new
  canonical states without convergence;
- the host resource guard handles CPU, memory, wall-clock, runnable-process
  capacity, and other runtime safety constraints.

A host-resource condition is not semantic divergence.  Evaluation may be
making semantic progress and still exhaust host resources.  Conversely, a fast
no-progress cycle remains a cycle even when it consumes little host capacity.

Host observations do not enter fixed-point identity or semantic progress.  Host
guard policy belongs to the runtime or admission boundary aligned with
[[file:45-13-demand-admission-backpressure-cleanup-capacity.org][the demand
admission RFC]].  It does not make POO Flow a scheduler.

Semantic-budget extension and host-resource authority are separate
continuations and cannot substitute for each other.  Test and benchmark
harnesses may validate the conditions but never provide their semantics.

* Cycle, divergence, and slow convergence

Semantic progress includes a new prototype-lineage state, a Capability-cell
transition to a new stable state, or a changed canonical identity for a partial
value.

Elapsed time, recursion depth, equivalent-object reconstruction, duplicate
dependency edges, and effect retry counts are not semantic progress.

#+begin_src mermaid
flowchart LR
    E["gerbil-poo observation"]
    R["same cell re-entered"]
    P["new semantic POO state"]
    C["fixed point converged"]
    B["observation budget exhausted"]
    CC["non-productive-cycle condition"]
    DC["divergence-budget condition"]
    SO["slow-progress observation"]

    E -->|"same cell with no progress"| R
    R -->|"non-productive cycle conditioned"| CC
    E -->|"semantic identity advanced"| P
    P -->|"stable value converged"| C
    P -->|"advancement exceeds budget"| B
    B -->|"divergence conditioned"| DC
    P -->|"slow progress within budget"| SO
#+end_src

A divergence continuation may explicitly extend the observation budget, inject
a resolution Profile, or terminate demand.  It never returns an incomplete
value or switches evaluators.

* POO-native observation budget

The observation budget is a Capability provided by an ordinary higher-order
Profile:

#+begin_src scheme
(compose profiles
  wendao-episteme
  convergence-policy
  production)
#+end_src

The budget counts semantic observation units, not wall-clock duration.  A
parent boundary may derive a bounded child budget.  A child may narrow but
cannot widen or replenish the delegation.

Budget extension requires explicit authority.  An authorized continuation
issues a new immutable budget Capability in a successor generation and records
a receipt.  It does not mutate the exhausted object.  This mechanism is not a
budget DSL and does not make POO Flow a scheduler.

#+end_src

* Conformance checklist

- [ ] Cycle identity includes root, generation, module, and Capability.
- [ ] Productive recursion is not rejected as a cycle.
- [ ] Observation units are immutable POO transition evidence rather than
  iteration counters.
- [ ] Units identify root, generation, module instance, Capability,
  predecessor, successor, lineage, provenance, and phase.
- [ ] Only changed canonical semantic identity consumes progress budget.
- [ ] Equivalent alias or re-export observations remain one canonical unit.
- [ ] Wall-clock, stack, allocation, logs, and effect retries are not semantic
  progress.
- [ ] Runtime pointers, closures, and continuations remain outside unit
  identity.
- [ ] Missing native transition evidence is an API gap, never synthetic
  progress.
- [ ] Cycle detection, semantic divergence budget, and host resource guard are
  independent.
- [ ] No-progress re-entry conditions immediately without consuming semantic
  budget.
- [ ] Host-resource exhaustion never becomes semantic divergence.
- [ ] Host observations do not affect fixed-point identity or progress.
- [ ] Semantic-budget and host-resource authorities remain distinct.
- [ ] Harnesses validate conditions but do not provide their semantics.
- [ ] Cycle, divergence, and slow convergence remain distinct.
- [ ] Only semantic POO state changes count as progress.
- [ ] Observation budget is a POO Capability, not a macro option.
- [ ] Child budgets cannot widen without delegated authority.
- [ ] Extensions create successor generations and receipts.
- [ ] No incomplete value, alternate evaluator, or scheduler is introduced.
