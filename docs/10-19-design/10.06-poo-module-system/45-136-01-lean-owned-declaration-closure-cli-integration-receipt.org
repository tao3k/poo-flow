* Ownership boundary

- Lake resolves and builds the requested Lean module.
- The Lean exporter imports the built environment and owns constant identity,
  reachability, dependency order, and owner-module projection.
- AXLE collapses generated constants to parsed source declarations and supplies
  source dependency evidence.
- The local projector owns the exact, namespace-preserving canonical source.
- AXLE performs round-trip extraction, =theorem2sorry=, and strict
  =verify_proof= over that exact source.
- Python does not parse Lean imports or invent a dependency-source package
  manager.

* Exact source-level fixed point

Let =C= be the dependency-first Lean constant closure, =D= the declarations
parsed by AXLE from the owner sources, and =pi: C -> D= the longest
source-owner projection. Generated constants such as structure constructors,
projections, and recursors therefore map to their source declaration.

#+begin_src typst
$ S_0 = pi(C) $

$ F(S) = S union
  { d in D | exists s in S, d in "deps"_D(s) } $

$ S^star = mu S. F(S) $

$ forall s in S^star:
  "deps"_D(s) subset.eq S^star $

$ "ExactSource" = "open-direct-dependency-namespaces"(
  "restore-original-namespaces"(
    "toposort"(S^star)
  )
) $

$ "BundleIdentity" = H(
  "roots",
  "toolchain",
  "environment",
  "resolved-sources",
  "declaration-identities",
  "canonical-source-digest"
) $

$ "AXLE-runtime-receipt" notin "BundleIdentity" $
#+end_src

The projector fails closed when:

- a Lean constant has no AXLE source declaration owner;
- a local AXLE dependency has no source declaration owner;
- the source-declaration graph contains a cycle;
- round-trip extraction emits a declaration set different from =S-star=;
- =theorem2sorry= or strict proof verification emits Lean or tool errors;
- strict verification is not =okay= or reports failed declarations.

** v1 stabilization rule

The declaration-closure contract remains
=poo-flow.lean-declaration-closure.v1=.  =source_range=, phase timing,
generated-declaration normalization, and root sharding are optional,
backward-compatible refinements of v1.  They MUST NOT introduce a v2 schema,
a second closure identity, or a parallel verification path.

Older v1 receipts without =source_range= remain readable.  Exact-source AXLE
verification fails closed with an actionable receipt when a required range is
absent; it MUST NOT silently return to whole-file projection.

Generated Lean declarations that share a selected source range MUST be
normalized to that source declaration before exact round-trip comparison.
This normalization changes neither the Lean-owned declaration graph nor the
v1 closure digest semantics.

Root sharding, when required for bounded AXLE latency, is execution planning
over the same v1 root declarations.  Each shard MUST retain the v1 closure
identity and the aggregate receipt MUST expose every shard result.

** Typst model of the v1 source quotient

#+begin_src typst
$ pi: D arrow S $

$ F(C) = C union
  { f | exists d in C, exists s,
    pi(d) = s and f in "Family"(s) and "Carrier"(f) } $

$ C^* = mu X. "EnvClose"(F(X)) $

$ C_S = { s | exists d in C^*, pi(d) = s } $

$ E_S = { pi(d) | d in E_D } $

$ "exact-roundtrip-v1" "iff" E_S = C_S $

$ s_i prec_s s_j "implies" i < j $

$ "FamilyClosed"(C^*) "and"
  "EnvironmentClosed"(C^*) "and"
  "DependencyWitnessed"(prec_s)
  "implies" "ReplayClosed"(C_S) $

$ "EnvClose"({T}) = {T}, quad pi(T) = s $

$ K in "Family"(s), quad "EnvDeps"(K) = {A}, quad pi(A) = a $

$ s prec_s a, quad a "not in" pi({T}) $
#+end_src

Here, =D= is the Lean environment declaration universe, =S= is the source
declaration universe, and =pi= maps constructors, fields, and generated
instances to their owning source declaration; it is absent for traversal-only
nodes without a source range.  =F= adds the inductive or structure anchor and
constructor dependency carriers from every selected source family.  =C^*= is
the least fixed point obtained by alternating that family expansion with the
ordinary environment dependency closure.  =E_D= is the AXLE extraction
result.  The relation =prec_s= contains source-level dependencies, including
reducible aliases that can disappear from environment constant dependencies.

The final three equations encode the counterexample found by the real
=structure= replay: the type declaration =T= has no environment edge to alias
=A=, but its constructor =K= in the same source family carries that dependency.
Thus environment closure of ={T}= is insufficient.  The Lean theorem
=sourceFamilyAndEnvironmentClosureImplyReplayClosure= proves the repaired
sufficiency condition, while
=environmentClosureAloneDoesNotImplySourceReplayClosure= preserves the
counterexample.

The equality is checked in the source quotient.  Lean-owned ranges and source
digests define the canonical source; AXLE extraction confirms the quotient but
does not replace canonical source with a larger reserialization.  Neither rule
changes the v1 receipt identity.

* Namespace preservation

AXLE =merge= is not the canonicalization authority for a multi-namespace exact
closure. The implementation probes established two concrete failure modes:

1. merging naked declarations removed namespace context and left qualified
   dependency references unresolved;
2. merging self-contained documents attempted a cross-namespace rename, which
   AXLE correctly rejected.

The exact projector therefore preserves each original declaration namespace.
For a declaration it opens only the namespaces of its direct, already emitted
AXLE dependencies. Opening every prior namespace was also rejected because it
made names such as =CapabilityConstraint= ambiguous.

This is a refinement of the broad =merge= wording in RFC 45-135: AXLE remains
the semantic parser and verifier, while exact cross-namespace composition is a
namespace-preserving local projection.
