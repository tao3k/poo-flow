#+title: Source-bound progress classification coherence
#+startup: overview

* Status

Proof-backed declaration-closure v1 refinement.

This document stabilizes =poo-flow.lean-declaration-closure.v1=.  It does not
authorize a v2 schema, a second closure identity, or a competing proof path.

* Context

=SourceBoundProgressContract= exposes independent predicates for semantic
equivalence, improvement, regression, incomparability, oscillation, completed
obligations, and remaining obligations.

An opaque contract can make every predicate true.  The same source coordinates
and subject evidence then support both =advancing= and =regressing=.  Even when
each subject is internally coherent, different subjects in one SCC may support
different exceptional classifications.

The receipt contains one =ProgressClass= value, but the enum alone does not
prove that:

- a subject has only one semantic relation;
- completed and remaining obligations are exclusive;
- the selected class is supported;
- all other supported classes were considered;
- selection is deterministic across a heterogeneous SCC;
- budget exhaustion dominates non-budget classifications.

* Decision

Progress classification closure has two independent levels.

1. Subject-level contract coherence rejects overlapping semantic relations and
   contradictory obligation states for each source-bound subject.
2. Receipt-level classification selection evaluates all supported candidates
   under an explicit, injectively ranked policy and requires the receipt class
   to be maximal.

The policy is a first-class proof object.  POO Flow supplies a risk-first
default, but the ordering is explicit rather than hidden inside an evaluator:

| Rank | Classification |
|------+----------------|
| 0 | =converged= |
| 1 | =advancing= |
| 2 | =stalled= |
| 3 | =incomparable= |
| 4 | =regressing= |
| 5 | =oscillating= |
| 6 | =budgetExhausted= |

Any alternative policy MUST prove rank injectivity and MUST keep
=budgetExhausted= above every non-budget class.  This ensures deterministic
selection without pretending that heterogeneous subject evidence is globally
mutually exclusive.

* Mathematical model

For every subject evidence =e=, distinct semantic relations cannot both hold:

#+begin_src typst
$ forall e, r != s:
  not (H_r(e) and H_s(e)) $
#+end_src

Obligation states are also exclusive:

#+begin_src typst
$ not ("Complete"(e) and "Remain"(e)) $
#+end_src

Let =S= be the supported classification candidates and =rho= the explicit
policy rank.  The selected classification =c^*= is supported and maximal:

#+begin_src typst
$ c^* in S and forall c in S:
  rho(c) <= rho(c^*) $
#+end_src

Rank injectivity turns maximal rank into a unique classification:

#+begin_src typst
$ rho(c_1) = rho(c_2) => c_1 = c_2 $
#+end_src

Budget exhaustion dominates whenever either deterministic remaining value is
zero:

#+begin_src typst
$ r_"semantic" = 0 or r_"scheduling" = 0
  => c^* = "budgetExhausted" $
#+end_src

* State model

#+begin_src mermaid
stateDiagram-v2
  [*] --> SubjectEvidenceBound: exact SCC evidence closes
  SubjectEvidenceBound --> RelationCoherent: one semantic relation per subject
  SubjectEvidenceBound --> FailClosed: overlapping subject relations
  RelationCoherent --> ObligationCoherent: complete and remain are exclusive
  ObligationCoherent --> CandidateSetBuilt: evaluate every supported class
  CandidateSetBuilt --> PolicyRanked: apply explicit injective ranks
  PolicyRanked --> BudgetDominates: a remaining budget equals zero
  PolicyRanked --> MaximalCandidate: both budgets remain positive
  BudgetDominates --> BudgetExhaustedSelected: highest policy rank
  MaximalCandidate --> UniqueReceiptClass: maximal rank and injectivity
  UniqueReceiptClass --> ClassificationClosed: compose progress evidence owner
  BudgetExhaustedSelected --> ClassificationClosed: compose deterministic budget owner
#+end_src

* Ownership boundaries

| Owner | Owns | Does not own |
|-------+------+--------------|
| Progress contract | domain predicates over one subject witness | choosing a class without coherence proof |
| Contract coherence closure | per-subject semantic and obligation consistency | cross-subject priority |
| Classification policy | explicit injective ranks and budget dominance | manufacturing candidate evidence |
| Selection closure | supported candidates, maximality, unique receipt class | fixed-point or budget accounting |
| Progress evidence closure | source coordinates and exact SCC evidence | implicit classification precedence |
| Deterministic-budget closure | typed remaining values and conservation | non-budget semantic ranking |

* Non-goals

- No declaration-closure v2.
- No globally hard-coded hidden evaluator priority.
- No assumption that all subjects in an SCC have the same semantic relation.
- No replacement of structural oscillation or deterministic-budget witnesses
  with opaque predicates.
- No retry or continuation authority.
