* Source and Module ownership

AI Agentic-context interprets Orgize's public =parse-org-rowan-events= tree.
Its semantic facade reexports that API; no replacement line parser is introduced.
=objects.ss= and =types.ss= own =AiAgenticContextOrgAnchor.= and its native Type.
=funs-anchors.ss= closes through =funs.ss= and =interface.ss=; =funs-session.ss=
constructs independent =SessionTask.= values. Session remains a composed Module;
Memory remains a Context Feature. The explicit effectful =session-host.ss= is an
opt-in Host build root, separate from the ordinary pure Module interface.

The parser token spans must partition the entire original UTF-8 source. Direct
property drawers under a document or an ordinary selected headline bind =:ID:=.
Literal/quoted drawers and additive =ID+= properties do not bind these anchors.
Document IDs are metadata anchors; headline IDs require membership in the
Context's selected open-headline ResultSet. Ambiguous document-wide IDs, empty
IDs, missing/unselected requests and duplicate requested IDs are refused.
Bounds are 256 document IDs and 32 requested anchors; IDs are 1..256 characters.

Every binding records the source digest, parser identity, selected projection,
Scope, Session, Turn, container and exact value byte span. Replay reconstructs
all fields from the original bytes. Context Task anchor references are fresh
binding digests, with native bindings retained on the Task. Session preserves
references without interpreting Org. This is source-byte replay, not physical
WorkTree authentication or action permission.

* Published local claim boundary

The Host's serialized owner enrolls copied source bytes and canonical Scope,
restriction/profile, Task revision, requested IDs and a registered grant identity
and generation. Its private bounded ledger holds the current source generation
and Session schedule. Returned snapshots copy strings and closed native objects.
A caller cannot mutate the private ledger through a returned receipt.

Claim publication checks exact current owner revision and source generation,
selected anchor availability, current grant generation, revocation, policy clock,
restriction lease, reader/destination and exact grant actor/Task. It then publishes
the independent pure Session claim into the private ledger. The Context grant
and temporal policy Hosts also enforce their construction owner thread, so these
local capabilities cannot change concurrently during the synchronous claim.
Existing ABI hosts declare the single-owner-thread contract; downstream ABI and
consumer tests remain the integration evidence for this change.

A source refresh cannot retarget the fixed consumer Scope. An active Attempt is
fenced into a pending recovery obligation. Deleted IDs or invalid refreshed input
publish a source-blocked entry; old Task input cannot continue to claim. Repeated
refresh preserves an existing obligation. Claim remains blocked while pending.
Enrollment capacity is 128 Sessions, and source/owner coordinates are bounded.
An exhausted recovery coordinate refuses refresh before mutation; an enrolled
snapshot is not a physical-source watcher. No terminal/isolation receipt resolver
or runtime reconciliation method is delivered in this Host.

=runtime-published?= refers only to the local ledger write. Receipts retain
=source-authenticated?=, =action-authorized?=, =provider-disclosed?=,
=provider-result-admitted?= and =durable?= false. The producer reference identifies
this local projection; it does not impersonate an MRR or Data admission receipt.

* Executable evidence

The unchanged normal compiler built the canonical production PackageSpec.
Eight Org anchor cases passed: document/parent/child IDs, UTF-8 spans, selection,
literal blocks, uniqueness, source/scope substitution and real Session claim.
Eight Host cases passed: once-only owner CAS, source fencing, deleted ID
invalidation, stale/foreign refresh, grant drift/revocation/policy expiry,
restriction expiry, owned snapshots and foreign-thread rejection. The five
existing Context grant/policy cases also passed after ownership enforcement.
All used the serial =just test-file= harness with =MODULE-OK=, =HARNESS-OK= and
final =OK=. Only test artifacts used the previously recorded O0 compiler setting.
The initial Task constructor exposed a POO lazy-slot variable-name recursion;
renaming the local binding repaired it under the same memory/watchdog gate.

=OrgAnchor.lean= proves seven named lookup/binding refusal laws; its audit finds
23 theorems including generated declarations. =ContextSessionClaim.lean= proves
nine named current-gate/owner laws; its audit finds 25 theorems. Both allow only
standard Lean axioms. Parser-produced rows and natural-number coordinates are
abstract inputs; neither file proves parser implementation or hash injectivity.

=ContextSessionClaim.qnt= checks 64 distinct states with an empty queue. Seven
matched mutations produce actual counterexamples for owner/source mismatch,
grant generation, revocation, clock expiry, obligation loss and foreign Scope.
The finite model has two refreshes, one claim and no reconciliation, matching the
bounded delivered Host surface. Its anchor availability abstracts unique selected
ID presence; concrete native parser controls cover that boundary separately.
A transient Apalache port conflict failed one run; the unchanged full group passed
after the listener exited. No watchdog or deadline was widened.

CI includes both native regression files, all Quint sources/cases and the extended
=PooFlowContextProof= target. Exact source hash/invariant metadata binding and six
proof-gate tests passed locally. Metadata binding is not semantic refinement;
automatic counterexample-to-native replay remains absent.

* Remaining end-to-end qualification

The Context Use v1 wire contract still has six fields. It does not carry the full
Session/Turn/Attempt/provider-destination envelope. A versioned successor must
resolve current authenticated source lineage and producer receipts, qualify its
native ABI with MRR and MRR Data consumers, and implement provider disclosure,
result admission and matching terminal/isolation receipts. Durable reconciliation,
artifact readiness, cancellation and multi-worker throughput require their own
runtime/backend evidence. This milestone closes local Org association and local
claim publication; it does not close the entire scheduling system.
