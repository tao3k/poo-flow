#+title: Semantic ABI v2 Scheme Datum Boundary

* Version and ownership

ABI v2 exports only =poo_flow_semantic_v2_open/call/source_register/close=
and =poo_flow_semantic_v2_result_release=. Result layout and owner-thread lifetime
are unchanged. Native POO objects remain inside Scheme; this encoding is an inert
FFI projection, not a semantic DSL or an evaluator. Legacy symbols and JSON
payloads are rejected. The descriptor reports version 2 and scheme-datum-v2.

* Inert grammar

#+begin_example
datum  := string | decimal | #t | #f | null
        | (list datum ...)
        | (object (string datum) ...)
decimal := -?(0|[1-9][0-9]*)(.[0-9]+)?([eE][+-]?[0-9]+)?

(object ("operation" "descriptor") ("payload" (object)))
#+end_example

Strings are UTF-8; escapes are only backslash, quote, n, r and t. Unescaped
control characters are forbidden. Object keys are unique strings. Encoders sort
keys; original MRR typed-row order remains unchanged. Integers fit signed 128
bits; decimal tokens have at most 64 characters and finite real values. null
is distinct from false and an empty list/object. Unsupported numeric types,
reader extensions, comments, quote/eval, dotted pairs and cyclic/shared reader
labels are rejected. Exactly one complete datum is consumed; trailing data fails.

The C host validates UTF-8, input size and parenthesis depth before Scheme entry.
Scheme validates the lexical subset before its reader, then validates constructor
shapes and duplicate keys. Python and Rust use non-evaluating bounded decoders.
Maximum input is 1 MiB, structural nesting 64, decoded nodes 262144 and Rust/Python
consumed output 16 MiB. Semantic profiles retain their tighter domain bounds.

* Acceptance and claims

=t/scheme-wire-test.ss= and Python/Rust wire tests exercise inert parsing and
negative inputs. Installed Python/C/Rust differential acceptance checks semantic
results on the rebuilt artifact. ASP Scheme owns the MRR benchmark and model
batch receipts. Old ABI results remain historical; re-encoding their receipts
would not qualify the new ABI. Required DeepSeek HTTP JSON is confined to the
provider adapter and is decoded before crossing project interfaces.

Publication request digests use the domain =poo-flow.temporal-publication-request.v2=
and canonical Scheme bytes. Existing historical database receipts retain their
original identities. Reusing an ABI v1 idempotency key with a v2 request fails as
a mismatch; there is no silent rewrite or JSON replay fallback. Historical lookup
remains distinct from a new commit. This qualification uses fresh v2 stores.
