#+title: POO Flow Session and WorkTree Context TLA+ models

These design-level models belong to POO Flow's =modules/session= and scoped
sharing policy. =ContextSession.tla= checks two Session identities and two
workers; =WorktreeContext.tla= checks two WorkTrees, two Sessions, and two
workers.  Normal TLC runs must complete without invariant violations.  Four
Session and six WorkTree guard mutations must violate their named invariants.

Run =just check-session-context-tla= from the POO Flow repository root.  The
runner requires actual TLC output within five seconds, caps each case at 45
seconds, and writes case logs and a JSON receipt under =.ci/session-context/=.

These checks do not prove a production Scheme/runtime refinement, actual
memory sharing authorization, physical CAS, effect reconciliation, or semantic
admission of MRR Context references.  Their scope is the explicit finite
transition relation in these two models.

An Org-backed Memory load model belongs in this POO Flow proof directory after
the source-bound loader contract is implemented.  It should cover source-byte
or query-pack change between parse and commit, stale Session resume, revoked
read/publish grants, and competing Memory-head writers.  The current models
carry abstract source cuts but do not model an Orgize document or query pack.
