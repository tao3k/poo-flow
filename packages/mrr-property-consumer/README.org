#+title: POO Flow MRR property consumer

This opt-in Rust package owns the caller handoff from a POO Flow source to
MRR's property Query API and MRR Data's physical executor. The caller supplies
an original GQL file, its expected source digest, admitted catalogs, a fully
verified snapshot and explicit physical/result budgets. MRR compiles, binds and
admits the candidate. MRR Data decodes Arrow from the verified closure and runs
the bounded DataFusion path. This package does not define a second parser or
semantic Query policy.

The Ubuntu test reads =case-profile-relations.gql= from POO Flow's fixed
=lambda-episteme= gitlink. It materializes typed test rows, publishes a CID
closure to an in-memory remote store, restores it into an empty local store,
and compares the source-bound MRR-admitted result against independently declared
rows. It also rejects a changed source digest before execution. The rows model
accepted Scenario/Case/Profile facts; they do not prove that the real
Lambda/Marlin process has exported those facts through a native typed boundary.
That export, a production S3 endpoint, and deadline/cancellation propagation
remain separate acceptance gates.

The MRR and MRR Data Git dependencies are pinned to the two Draft PR heads
that expose this handoff. Re-pin both after their eventual squash merges, then
rerun the same Ubuntu job at the new exact heads.
