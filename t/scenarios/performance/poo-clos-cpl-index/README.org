#+title: POO CLOS CPL identity-index scenario

This A/B scenario compares the removed repeated-constraint topological loop with
the production =poo-clos-topological-order/identity= function on the same
180-node linear class graph.  It requires identical ordered results, records
the old algorithm's constraint inspections, and admits the candidate only when
its five-sample median is lower.  Wall time is a local qualification receipt;
the durable improvement is the replacement of repeated constraint rebuilding
with one outgoing-edge and indegree index.

The same process then runs only the production algorithm over a 20,000-node
linear graph.  This separates comparison scale, where the old implementation
must still terminate, from capacity scale, where rerunning the cubic baseline
would make the qualification itself unusable.

Run from the repository root:

#+begin_src sh
gxi t/scenarios/performance/poo-clos-cpl-index/scenario.ss
#+end_src
