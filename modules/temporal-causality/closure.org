* Concrete source and step correspondence

The emitter reconstructs data/check/config from replayed POO values. Hypothesis
v2 preserves =ModelIdentity=, family mode and canonical limited frontiers.
TLC independently computes each expected classification; full traversal checks
all candidate orders and terminal stutter retains deadlock checks.

Behavior v1 emits a complete native reachable-state transition table. The
native table uses the same private step function as native query exploration.
TLC =NativeStepsSoundness= independently checks every emitted row against guard,
assignment and intervention-clamp semantics. =StepAgreement= checks that every
TLC reachable state/action result occurs in that table. Initial values and the
variable-order bijection are checked, as are forced native witness/counterexample
states and final property truth. An incomplete native table cannot admit a
correspondence bundle. Deleting a row while retaining classification and witness
states produces a =StepAgreement= violation; changing a witness state produces
=TraceAgreement= failure, and a family-mode mutation violates
=TerminalAgreement=.

=poo-flow-tla-check-correspondence!= binds model/profile and complete step-table
identity to the exact checked bundle. Its semantic imports have built-in owned
source pins; callers cannot replace them with a trivial checking program.
The private backend binds every source/config byte, the complete pinned Java
Home/TLC inventory, and output. Ambient imports/options cannot supply omissions.

Lean =FiniteStepTable= proves projected step equivalence under injectivity,
trace transport and source-bound table transport under explicit identity/row
premises, and rejection of a mismatched source identity. =BehaviorProjection=
proves schedule/trace and property laws under commuting steps;
=HypothesisClassification= proves the finite classification laws;
=DurationBudget= proves conservation, monotone remaining balance, delegation and
failure-no-refund. The exact admitted finite inputs have separate executable
TLC correspondence evidence. This does not prove the Scheme/TLC implementations
for arbitrary source programs. Correspondence receipts retain
=semantic-refinement? #f= and =action-authorized? #f=; replay checks identity
consistency under the trusted host execution premise.

* Runtime and trust contracts

- Late reconciliation replaces one authenticated existing observation in the
  same source/domain. It requires fresh source sequence, preserves the old model
  and watermark, and triggers a newly admitted revision/retraction.
- The host approves the complete literal model source and its assumptions. The
  fixed native evaluator replays the actual query in the publication context;
  opaque proof labels, caller admission flags and unfinished search cannot sign.
- Both real runtimes atomically commit pointer and signed effect. Signed CAS
  observations do not reserve the pointer. Durable exact replay preserves the
  original effect; nonce collisions and competing predecessors are rejected.
- Shared duration budgets use signed balances/delegations and one-shot grants in
  a trusted shared SQLite coordinator. Spending precedes the publication
  transaction, so crashes and failures do not refresh grants. Elapsed monotonic
  duration is checked before commit; this does not preempt CPU work or bound the
  final filesystem commit syscall. It is not an independent cross-host service.
- Native worker children perform a single pure evaluation or completed test
  harness, flush output and propagate status without macOS dyld unload latency.
  Application runtimes retain their ordinary lifecycle and persistent resources.
  The five-second no-output gate remains; the expanded 19-module native matrix
  has a bounded 180-second total deadline.
- Host-owned interpreter/compiled modules, keys, OS and filesystem are explicit
  premises. Current test tool pins qualify the local installation, not external
  release approval. Complete malicious database rollback needs an external
  monotonic authority; signed stored fields alone do not prevent it.
- Progress is bounded with fairness =none=. No fair infinite-progress,
  unrestricted source-interpreter or actual-causation claim is issued.
