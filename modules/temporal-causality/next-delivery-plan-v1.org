* Priority corrections from the audit

1. Dependency and ABI evidence must refer to the same actual producer closure.
   Update the ASCENT pin before accepting a fresh native Library artifact.
2. In-process source replay and revision journals are bounded basic slices.
   Durable support withdrawal, current selection and journal recovery remain
   separate from those slices.
3. The C SQLite first-root CAS and Data Backend conditional commits have separate
   evidence. Two individually passing stores do not establish one atomic
   cross-module publication. Define the authoritative commit owner and bind
   source/proof/policy guards through that commit; do not treat sequential writes
   as an atomic transfer.
4. IFC visibility subset checking is only a partial checker. Label composition,
   provenance/lease checks, authorized declassification and the actual transfer
   fence must qualify before an IFC-controlled publication claim.
5. After a source or grant change, an immutable historical commit receipt proves
   the old outcome. Fresh current applicability/effect permission needs its own
   check against the new source/policy state.

* Runtime and reporting gates

Five seconds without genuine completed-work output is failure. Native runtime
qualification retains its 45-second total deadline. Report actual build,
process exit, local semantic checks, exact-head remote CI, model behavior and
benchmark evidence separately. No synthetic heartbeat, relaxed timeout,
automatic response repair or construction-only performance claim closes a gate.
